# # DJ Harmony Website Manual Testing Project

## Project Overview

This project demonstrates the Manual Testing performed on the DJ Harmony website. The objective was to validate website functionality, navigation, responsiveness, browser compatibility, operating system compatibility, and overall user experience across different devices and platforms.

## Website Modules Tested

* Home Page
* About Us Page
* Services Dropdown

  * DJ for School Event
  * DJ for Corporate Party
  * DJ for Culture Event
  * DJ for Birthday Party
  * DJ for Wedding Party
* Gallery Page
* Blog Page
* Contact Us Page
* Book Now Button
* Call Now Button
* Footer Links
* Social Media Links

---

## Testing Activities Performed

### Functional Testing

* Verified page navigation and redirections.
* Validated Services dropdown functionality.
* Tested Book Now and Call Now buttons.
* Verified Contact Us page accessibility.

### UI Testing

* Checked page layouts and alignment.
* Verified buttons, menus, images, and text visibility.
* Validated consistency of fonts and styling.

### Responsive Testing

* Tested website responsiveness on:

  * Desktop
  * Laptop
  * Mobile Devices

### Cross-Browser Testing

Website functionality was validated on:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox

### Operating System Testing

Website compatibility was verified on:

* Windows 10
* Windows 11
* Android

### Compatibility Testing

* Verified consistent behavior across browsers.
* Checked responsiveness on different screen sizes.
* Validated UI consistency across operating systems.

### Defect Reporting

* Identified and documented UI and functional issues.
* Logged defects with severity and priority.
* Retested resolved defects.
